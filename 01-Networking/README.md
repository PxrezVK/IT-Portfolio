# 01 - Networking

Documentación técnica de prácticas y laboratorios de redes realizados con Cisco Packet Tracer.

## Objetivos

- Diseñar y simular infraestructuras de red.
- Configurar routers y switches.
- Comprender y aplicar los protocolos TCP/IP.
- Implementar redes VLAN.
- Realizar pruebas de conectividad y resolución de problemas.

## Áreas de trabajo

| Área | Descripción |
|---|---|
| Cisco Packet Tracer | Diseño y simulación de laboratorios de red. |
| TCP/IP | Direccionamiento, protocolos y configuración de red. |
| VLAN | Segmentación y comunicación entre redes. |

## Laboratorios

Los laboratorios se irán incorporando a medida que se diseñen, configuren y documenten.
